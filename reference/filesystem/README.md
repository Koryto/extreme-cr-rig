# Filesystem Reference Template

This directory contains the filesystem-based reference transport for the initial release of `extreme-cr-rig`.

It includes:

- the role-specific runbooks
- the transport entrypoint
- the round template

## Layout

```text
reference/filesystem/
|-- START_HERE.md
|-- LEAD_RIG_INIT.md
|-- REVIEWER_RIG_INIT.md
`-- round_template/
```

## Purpose

Use this directory when the active transport is the filesystem.

For actual operation, start with [START_HERE.md](START_HERE.md).
